# MCP Control Plane — VISION

## Project Role

Ser a ponte interoperável para automação, IDEs, scripts e Towers externas.

## Design Principles

1. MCP adapta; Tower executa.
2. Remoto é feature v1, não backlog.
3. Tool local não auto-conecta ao próprio MCP.
4. Auth e redaction são iguais ao App Server.

## Out of Scope

MCP client de providers/tools existente, scopes finos e federation protocol.
