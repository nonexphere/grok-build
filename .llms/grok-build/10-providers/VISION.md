# Providers — VISION

## Identidade

Uma experiência coerente de login, catálogo, binding e inferência para OAuth e
API keys, sem apagar o caminho custom-model de power users.

## Norte

1. v1: Codex honesto + BYOK OpenRouter/Groq/Cloudflare L1–L3.
2. v2: capability metadata/per-model backend, keyring e UX multi-account plena.
3. v3+: descriptors adicionais sem cross-cutting match arms.

## Não faz

- provider failover automático, billing ou OAuth não autorizado;
- prometer feature parity entre Chat Completions e Responses;
- substituir custom TOML.
